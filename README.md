|---|---:|

## GitHub Pagesで公開

1. ZIPをパソコンで展開します。ZIPのままアップロードしないでください。
2. GitHubで新しいリポジトリ（例：`eiken4-training`）を作成します。
3. `index.html` がリポジトリの一番上に来るように、展開した中身をアップロードして保存します。外側のフォルダごと入れないようにします。
4. リポジトリの **Settings → Pages** を開きます。
5. **Source: Deploy from a branch**、**Branch: main**、**/(root)** を選んで **Save**。
6. 公開処理が終わったら、Pages画面に表示されるURLを開きます。

GitHub Freeでは公開リポジトリを利用します。静的ファイルだけで動くため、APIキー・サーバー契約・npmのインストールは不要です。ドットで始まる `.nojekyll` も同梱しています。

公式手順（2026-09-29確認）：
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 使い方

- 「10問チャレンジ」はリスニング以外の5分野から2問ずつ出題します。
- 分野別練習は最大10問。読解・リスニングは同じ素材の設問をまとめて最大9問です。
- 各分野で未出題を優先し、その後に間違い、正解済みの順で出題します。
- 「まちがいを復習」では、直近で間違えた問題だけを繰り返せます。正解すると復習待ちから外れます。
- 読解と音声の複数設問は、1設問を1問として数えています。
- 並べ替えはタップで単語を選びます。選択済み単語を押すと戻せます。一部の別語順も正解として登録しています。
- リスニングは端末の英語合成音声。再生ボタンを押すと流れます。速度変更・聞き直し・解答後のスクリプト確認ができます。
- 全問が試験と同じ形式ではありません。語彙確認や全文並べ替えも含む練習用です。本番の確認には画面下部の英検公式ページをご利用ください。練習正答率はCSEスコアや合否判定ではありません。

## 学習記録

記録は利用中のブラウザの localStorage に保存されます。旧89問版と同じURL・同じブラウザなら記録を引き継ぎます。

別の端末・ブラウザ・URLに自動転送されません。Sites版からGitHub Pages版へ移った場合は別の記録になります。ブラウザのデータ消去やプライベートモードでは記録が消えることがあります。

## ファイル

- `index.html`：画面の入口
- `style.css`：スマホ・PC用のデザイン
- `data.js`：固定1,000問の問題集
- `learning.js`：出題優先順と別語順の採点
- `app.js`：画面・解答・記録・音声
- `content/`：編集用の問題データ。`original.json` は旧版89問で、IDを維持します。
- `scripts/build-content.py`：問題集の再生成と件数・重複・選択肢検証（Python 3）
- `scripts/check-app.cjs`：出題・採点・記録のロジック確認（Node.js）

通常の利用や公開には scripts を実行する必要はありません。問題を編集した場合だけ、ZIPを展開したフォルダで以下を実行します。

```sh
python scripts/build-content.py
node scripts/check-app.cjs
```

元の開発用構成に `dist/` がある場合は dist/data.js を更新します。GitHub用ZIPではルートの data.js を更新します。
